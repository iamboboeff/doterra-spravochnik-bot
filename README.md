# Telegram-справочник «Бережное Врачевание»

Отдельный бот по восстановленному тематическому указателю. Он не изменяет бота
участников и админ-бота в соседних каталогах.

## Возможности

- 99 тем и 170 восстановленных публикаций;
- алфавитный каталог с постраничной навигацией;
- поиск одновременно по заголовкам и полному тексту;
- публичная редакция текста без имён адресатов, приветствий и ссылок на
  удалённый чат; исходный архив остаётся локально и на хостинг не загружается;
- карточки публикаций с переходом к предыдущей и следующей;
- отметка публикаций, у которых в архиве не сохранилось медиа;
- кнопки консультанта, приглашения и помощи;
- информационный дисклеймер.

## Подготовка

```bash
npm install
npm run build:content
cp .env.example .env
```

Заполните `.env`:

- `BOT_TOKEN` — токен нового бота от `@BotFather`;
- `BOT_USERNAME` — имя бота без `@`;
- `CONSULTANT_URL` — ссылка вида `https://t.me/username`;
- `SOURCE_INDEX` — путь к исходному текстовому указателю.

## Запуск

```bash
npm test
npm start
```

При переносе на хостинг загрузите проект вместе с `data/content.json`, затем
добавьте переменные окружения. Команда запуска: `npm start`.
