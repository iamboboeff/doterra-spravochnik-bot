# Telegram-справочник «Бережное Врачевание»

Отдельный бот по восстановленному тематическому указателю. Он не изменяет бота
участников и админ-бота в соседних каталогах.

## Возможности

- 99 тем и 170 восстановленных публикаций;
- алфавитный каталог с постраничной навигацией;
- поиск одновременно по заголовкам и полному тексту;
- публичная редакция текста без имён адресатов, приветствий и ссылок на
  удалённый чат; исходный архив остаётся локально и на хостинг не загружается;
- карточки публикаций с переходом к предыдущей и следующей;
- отметка публикаций, у которых в архиве не сохранилось медиа;
- кнопки консультанта, приглашения и помощи;
- информационный дисклеймер.

## Подготовка

```bash
npm install
npm run build:content
cp .env.example .env
```

Заполните `.env`:

- `BOT_TOKEN` — токен нового бота от `@BotFather`;
- `BOT_USERNAME` — имя бота без `@`;
- `CONSULTANT_URL` — ссылка вида `https://t.me/username`;
- `SOURCE_INDEX` — путь к исходному текстовому указателю.

## Запуск

```bash
npm test
npm start
```

База указателя лежит в `content/content.json` и едет вместе с репозиторием —
собирать её на хостинге не нужно, исходный архив туда не попадает.

## Деплой на Bothost

Заполните форму создания бота:

- название: `Бережное врачевание`;
- платформа: `Telegram`;
- язык: `Node.js`;
- образ: `node:20 Alpine`;
- Git URL: `https://github.com/iamboboeff/doterra-spravochnik-bot.git`;
- ветка: `main`;
- локация: `Нидерланды`;
- главный файл (Дополнительные настройки): `index.js`.

Переменные окружения задавать не обязательно — рабочий `.env` лежит в
репозитории, и бот берёт значения из него. Если заполнить поля в панели, победят
они: пустая переменная от хостинга значением не считается.

Три грабли Bothost, на которые тут уже наступили (не откатывайте эти решения):

1. **`WORKDIR` не должен быть `/app`.** При старте контейнера `/app`
   монтируется с хоста и скрывает всё, что туда положил образ, включая
   `node_modules`, — сборка зелёная, а контейнер падает с `MODULE_NOT_FOUND`.
   В `Dockerfile` рабочий каталог — `/usr/src/app`.
2. **Никаких папок с именем `data`.** Агент вырезает их из репозитория вместе с
   исходниками, поэтому база лежит в `content/`, а не в `data/`.
3. **После смены главного файла нужен новый деплой,** перезапуска мало.

После успешного запуска в логах появится:

```text
✓ @ber_vranch_bot запущен: 99 тем, 170 постов
```
